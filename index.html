HTML (HyperText Markup Language) is used to create web pages. It defines structure like text, images, and links.

Example:

<h1>Hello World</h1>

Headings are used to define titles. HTML has 6 levels (h1 to h6).

Example:

<h1>Main Heading</h1>
<h2>Sub Heading</h2>
<h3>Small Heading</h3>

Paragraphs are written using <p> tag.

Example:

<p>This is a paragraph</p>
<b>Bold Text</b>
<i>Italic Text</i>

Links connect one page to another using anchor tag.

Example:

<a href="https://google.com">Visit Google</a>

Images are added using img tag.

Example:

<img src="image.jpg" alt="Sample Image">

Lists are used to group items.

Example:

<ul>
  <li>Item 1</li>
  <li>Item 2</li>
</ul>

Tables display data in rows and columns.

Example:

<table border="1">
  <tr><th>Name</th><th>Age</th></tr>
  <tr><td>Karthik</td><td>20</td></tr>
</table>

Forms are used to collect user input.

Example:

<form>
  <input type="text" placeholder="Name">
  <input type="email">
  <button>Submit</button>
</form>

Buttons perform actions like submit or click.

Example:

<button>Click Me</button>

Div is a block container. Span is inline.

Example:

<div>Block Element</div>
<span>Inline Element</span>

CSS is used to design HTML pages.

Example:

body {
  background: lightblue;
}

These tags help structure the webpage.

Example:

<header>Header</header>
<section>Content</section>
<footer>Footer</footer>
